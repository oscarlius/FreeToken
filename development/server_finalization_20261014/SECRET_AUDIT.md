## 已确认的问题

公开研究仓库 `main` 的历史中有真实 SSH 密码，涉及以下 8 个旧运维脚本的 `REMOTE_PASS` 字面量：

- `check_503_log.py`
- `check_expert_load.py`
- `check_ft_serve_args.py`

- `check_srv_log.py`

确认方法：只在内存中与已有私有连接配置作精确比较。报告、测试与终端输出不包含密码、片段或密码摘要。此前常见令牌格式扫描没有覆盖这种普通 SSH 口令，不能作为凭据已安全的证明。

- 8 个当前脚本移除了服务器主机、用户名及密码字面量，改用 `FT_SSH_HOST`、`FT_SSH_USER`、可选 `FT_SSH_PASSWORD`；不设置密码时保留既有 SSH key/agent 行为。
- 保留原连接超时、主机密钥策略及具体运维功能，不扩大改动范围。
- CPU 回归 3 项通过；编译与实际密码精确零匹配检查通过；非作者审核 PASS。
- 修复及精简 README 已通过普通推送发布为 `668c4db`。这一步只清除了当前版本中的密码，未清除历史记录。
