# T10 重跑的路径与比较边界

当前状态：T17 R023 为实测反例；T10 接受性重跑等待 T17 通过及统一树验证。
本文件是后续测量协议，不是 GPU 结果，也不修改已封存的历史结论。

## 历史协议核实

已只读检查 R006/R017 各 B1/B2/B3 的实际 `SERVE_CMD.txt` 与解析参数。
六个服务均为 `prefill_layer_major=false`，`max_prefill_length=4096`、
`max_extend_tokens=4096`、`mamba_host_slots=0`，启用 D2D 和 special-token
checkpoint。R006 的 cache-report 关闭；R017 开启，另有开发 logits dump。
因此历史 33/36 是普通预填路径的冷热差异。更换成层优先后得到的分歧计数，
不能直接解释为历史 33/36 已被 D14 修复。

## 同一代码树上的两个明确实验

| 实验 | 预填模式 | 作用 |
|---|---|---|
| 普通路径重跑 | layer-major=false | 与历史 33/36 作相同路径的比较 |
| D14 路径重跑 | layer-major=true | 测量层优先命中续算修复后的行为 |

两项都绑定同一经过门验证的完整提交、模型与扩展库。每项使用三个独立
服务进程，各执行历史 12 轮冷/热协议，保留原来的 reverse-cold 与
forward-warm 顺序、消息输入、工具及 thinking 设置、采样上限与停止口径。
先核对输入 ID 哈希及实际参数，再比较冷对冷、热对热、冷对热的实际采样
ID、完整输出与结束原因。协议差异逐项记录；不得把两条路径的计数混合。

通过外部测试包装器观察真实 `UserMsg` 输入和 `DetokenizeMsg` 采样 ID，
不使用重新分词的输出当作采样证据。包装器、最终运行树和原始 HTTP 回执
都冻结并记录 SHA256。正常生产配置中不启用该工装。

分叉点 logits 通过返回 raw logits 的模型/引擎方法抓取一次，再由原方法
返回原 tensor，保持原采样调用。层优先路径可包装
`Engine._forward_layer_major`，其返回发生在 `Engine.forward_batch` 的采样
之前。普通路径需对应的采样前返回点。每次抓取绑定 UID、准确输入 ID SHA、
token 位置、tensor dtype/shape/字节哈希、top-2 值及差距；零次、多次或
批次/UID 不匹配均拒绝。无需为此合入 D03 的其他运行时改动。

## R023 的限制

8192 边界的短尾段，D2D 四角色复制均逐位一致，但冷/热续算结果在第37个
采样 token 分叉。冷臂执行 0→512 的 anchor 段，再执行层优先 512→8257；
热臂执行普通短预填 8192→8257。它是有效反例，但未隔离恢复逻辑与预填
路径差异。其余边界尚未完成冷/热比较，不能算作通过。

后续归因应先比较 L=8192 的捐赠状态和独立重算状态，再控制续算路径进行
对照。保留原 T17 失败及原严格门；诊断实验不能自行替代接受条件或放宽
逐位检查。原始张量继续留在服务器。
