## Common E2 execution corrections

1. Wait for real E2-base tag and T16 gate-D00, then issue new E2 round IDs.
2. Capture `freetoken.__file__`, exact tag/commit, tracked-clean state, compiled
   extension provenance, launch/ENV, parsed args, and immutable trace hashes.
3. For replay comparisons, use `messages_sha` and `trace_messages_sha`; never
   infer identical prompts from `--fresh-note`, arm names, or the replay index.
4. Preserve T03 checkpoint semantics: `REPS=5` means pair 0 cold and pairs 1--4
   hot, never a five-hot median.
