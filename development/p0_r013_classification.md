# P0-3：R013 分叉分类

只读核查已完成：431 个封存清单条目通过，22 个 K1 capture 构成 11 个独立进程对；各对 FP32 logits 逐位相同。历史 11 个分叉按位置分为第 0 token 3 个、1–10 token 5 个、48 以后 3 个。

第 0 token 三处实测 top-2 差为 0.375、0.250、1.875；另有 fork03 差为 0，属于完全平局。这里报告数值，不另造近似平局阈值。

这 11 对的协议是双方各启动 fresh 服务、各自预热同一前缀，再进行 P+X/K1 capture。它证明该场景可以跨进程逐位复现。结合 R017 的 cold-cold 36/36 和 warm-warm 36/36，历史差异支持确定性的路径差异；R013 不是直接冷对热实验，全部 `restore_proof` 为 null，不能单独完成冷热机制归因。

R017 的旧冷对热分歧为 33/36，真实 token 分叉点 11 个。修复版 D14 T10 尚未重跑；分歧变化和 D14 因果数量继续待测。
