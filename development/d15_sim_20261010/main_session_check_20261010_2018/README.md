- H 是半衰期，单位为 ensure 调用；384 次调用 = 8 个解码步。H 只按 seed12k 在 {96, 192, 384, 768, 1536} 中选取，其余三组是留出结果。
- LRFU 的淘汰键是 crf·2^(−(now−last)/H)，命中时 crf ← 1 + crf·2^(−(now−last)/H)。它可以改写成每槽的静态浮点键 log2(crf) + last/H：这个键只在访问时更新，argmin 结构与现有 `(usage, slot)` 相同。
- lru2（倒数第二次使用）在 two 组上为 56.594%，属于 LFU 污染，已放弃。
- 3390 槽对应"借用闲置 KV 页"的估算：98,304 窗口共 1,536 页，22K 上下文约用 347 页，闲置约 1,189 页。按 T12 的单位，1 页 = 1,615,806 B，1 槽 = 2,764,824 B，折合约 694 槽，2700 + 694 ≈ 3390。
- 3600 槽在单卡上靠缩窗口达不到：49,152 窗口对应 3,149 槽，这个窗口的全部 KV（1.16 GiB）折算下来约 450 槽。
