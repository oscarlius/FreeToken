## 4. 主会话判断：怎样最快拿到第一项自有收益

1. **D09 启用路径（T17 + T2）。**
   - 代码、CPU 测试、默认门都已就绪，只差一个 GPU 窗口。
   - 预测：受影响轮次的首 token 约 5.3 s → 2.8 s（−47%）；seed_real 5 轮中 2 轮受影响。
   - 只要 T17 通过、T2 的实测接近预测，这就是论文里第一个"本文机制、实测收益"。
2. **OOM 止血。** 这不是收益，是生产缺陷，但 87–95K 正是用户的目标负载。
3. **hybrid 的 fp32 复测。** 如果证实，hybrid 这个可选模式会更快，而且去掉激活量化。
4. **D20 解冻 → D12（M5）。** 潜在收益大，但前置门多，至少要两三个窗口。

M2、M3、M4、M6 都不建议现在做：前两项有推演或代价依据，M4 已被 hybrid 超越，M6 依赖 M1–M5。
