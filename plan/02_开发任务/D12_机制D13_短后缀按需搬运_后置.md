## 目标（立项后）

后缀 n 很小（重发、重试、短追问、地板情形）时，预填只搬本层路由实际用到的专家，而不是整层，把首 token 从约 2.7 s 降下来。

## 立项条件（由 T06 给出）

- 真实循环中 `n ≤ 64` 的轮次占比，以及这些轮次的真实 f(n)。若占比很低（论文 §6.7 的 T2 数据为 1/11），收益只剩重发/重试/短追问与地板情形，由总负责人判断是否值得 3–6 人日。

## 已知的代价与挂点（上游 d3512b4 核实）

| 代价（§6.7） | 挂点 |
|---|---|
| 1. 路由要等本层注意力算完才知道，按需搬运无法提前预取下一层，搬运落在关键路径 | `layers/moe.py:220-224`（预填/解码分流，只按 `ctx.batch.is_prefill`，无 token 数阈值） |
| 2. 预填 GEMM 假设位置等于专家号，需改用 slot 视图或退回解码 GEMV | `layers/moe.py:418-421`（`slots=None if n is not None else topk_ids, n=n`，预填传 `n=num_experts`） |
| 3. 按需搬运会挤占解码的缓存 | 复用解码的 `lru_ensure` / `ensure_experts`（`layers/moe.py:261-296`） |
| 整层搬运路径 | `layers/moe.py:347-384`（加长度阈值处） |

## 立项时必须写清的验收门（框架）

- 默认关；默认路径逐位一致（T16）。
