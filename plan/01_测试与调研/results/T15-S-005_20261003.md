摘录：

1. 「Peer to Peer is not supported on 4090. … The fix doesn’t enable peer-to-peer on these cards.」
2. 「SHM is used between devices when peer-to-peer cannot happen, therefore, host memory is used.」
3. 「GeForce cards don't support GPU Direct P2P … the traffic cannot stay local to the PCI switch and has to go back to the CPU.」
4. 帖中 `NCCL_P2P_DISABLE=1` 的 `all_reduce_perf` 输出 `# Avg bus bandwidth : 5.67265`。当时 `cudaDeviceCanAccessPeer` 曾误报 CAN，与后来官方「应报 No」不一致。
5. 笔记本原文：`Device=0 CANNOT Access Peer Device=1`，P2P 关闭时单向带宽矩阵约 21.91 GB/s。
6. aikitoria 说明：4090 走 PCIe BAR1；并列出无 P2P 时 NCCL SHM 约 2.7 GB/s 的对照。改官方驱动路径，不建议。
7. 论坛参与者写跨插槽要靠 `numactl`，否则插槽间链路成为瓶颈。没有单独的 UPI GB/s 官方表。

`NCCL_DEBUG=INFO` 用来区分路径。文档定义了 P2P 与 SHM 两种传输，但本卡没有在目标机器上抓日志，具体字样留到实测清单。
