## 步骤

### 1. 建目录并上传清单

### 2. 校验清单中已填的哈希（只读）

```bash
$SSH 'cd /data2/_shared/runs/ft_releases/FTD-20261003-1 && /data2/FreeToken/venv/bin/python - <<"EOF" > verify_listed.txt 2>&1; tail -5 verify_listed.txt
import json, hashlib
m = json.load(open("manifest.json", encoding="utf-8"))
def h(p):
    x = hashlib.sha256()
    with open(p, "rb") as f:
        for b in iter(lambda: f.read(1 << 20), b""):
            x.update(b)
    return x.hexdigest()
ok = bad = miss = 0
items = []
for d in m["directories"].values():
    items += [(f["path"], f["sha256"]) for f in d["files"]]
for r in m["rounds"]:
    rj = r["round_json"]
    if rj.get("path") and len(rj.get("sha256", "")) == 64:
        items.append((rj["path"], rj["sha256"]))
    items += [(b["path"], b["sha256"]) for b in r["batch_logs"] if len(b["sha256"]) == 64]
items += [(b["path"], b["sha256"]) for b in m["global_batch_logs"] if len(b["sha256"]) == 64]
for e in m["external_sources"]:
    if "sha256" in e and "path" in e:
        items.append((e["path"], e["sha256"]))
seen = set()
for p, s in items:
    if p in seen:
        continue
    seen.add(p)
    try:
        a = h(p)
    except FileNotFoundError:
        miss += 1; print("MISSING", p); continue
    if a == s:
        ok += 1
    else:
        bad += 1; print("MISMATCH", p, "listed", s, "now", a)
print("VERIFY ok=%d mismatch=%d missing=%d" % (ok, bad, miss))
EOF'
```

期望：`VERIFY ok=<N> mismatch=0 missing=0`，或者只有 `/data2/_shared/model_hub_dashboard/data/rounds.json` 一项 `MISMATCH`（它是可变文件，清单里已标 `volatile`）。

- 只有 `rounds.json` 不一致 → 继续，在 `landing.json` 里记录当前值（步骤 4）。
- 其他任何 `MISMATCH` 或 `MISSING` → **停**，把 `verify_listed.txt` 末 30 行贴进结果文件，上报「历史工件在 21:40 之后被改动」。不要修改清单。
