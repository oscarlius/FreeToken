## 背景（执行者只需知道这些）

- D0 记录 `d0_prefill.jsonl` 每行是一个预填段：`chunk`（进程内从 0 计数）、`wall_s`、`h2d_gib`、`d2d_gib`、`layers[{layer, copy_ms, compute_ms, d2d_ms}]`。**没有请求编号。**
- `serve.log` 每个预填段打印一行 `Prefill batch, #new-seq: …, #new-token: N, #cached-token: M, …`。
- 已核实（规划阶段只读）：同一进程内 D0 记录数 = `Prefill batch` 行数 − 1（最后一段在进程退出前未落盘），`chunk` 回到 0 表示换了进程。所以「第 i 个 D0 记录 ↔ 该进程第 i 个 `Prefill batch` 行」。**只有这个计数关系成立时才能对齐**，否则停。
- 一整池 = 63.46 GiB（`h2d_gib + d2d_gib`）；有部分命中时常见 `h2d 57.73–58.59 + d2d` 余量（RESULTS_E1、论文 §6.2）。

## 步骤 1：对齐 E1-R003-v2（含 recomputed=1 请求）

已知 v2 的四个进程按时间顺序为 `gen → A → B → C`（`serve.log` 修改时间 16:22 / 16:30 / 16:38 / 16:46），D0 文件里 `chunk` 在第 23、79、137 行回零。

```bash
$SSH 'cd /data2/_shared/runs/ft_rounds && /data2/FreeToken/venv/bin/python - E1-R003-v2/d0_prefill.jsonl E1-R003-v2/gen/serve.log E1-R003-v2/A/serve.log E1-R003-v2/B/serve.log E1-R003-v2/C/serve.log <<"EOF" | tee /tmp/s001/v2_align.txt
import json, re, sys
d0 = [json.loads(l) for l in open(sys.argv[1])]
segs, cur = [], []
for r in d0:
    if cur and r["chunk"] <= cur[-1]["chunk"]:
        segs.append(cur); cur = []
    cur.append(r)
segs.append(cur)
logs = sys.argv[2:]
print("D0_PROCESSES", len(segs), [len(s) for s in segs], "LOGS", len(logs))
if len(segs) != len(logs):
    print("ALIGN-FAIL process count"); sys.exit(3)
pat = re.compile(r"Prefill batch.*#new-token: (\d+), #cached-token: (\d+)")
for lg, seg in zip(logs, segs):
    lines = [m for m in (pat.search(x) for x in open(lg, errors="replace")) if m]
    print("PROC", lg, "prefill_lines", len(lines), "d0_records", len(seg))
    if len(seg) != len(lines) - 1:
        print("ALIGN-FAIL count", lg); continue
    for i, (m, r) in enumerate(zip(lines, seg)):
        new, cached = int(m.group(1)), int(m.group(2))
        if new <= 64:
            L = r["layers"]
            print("SEG i=%d new=%d cached=%d wall_s=%.3f h2d_gib=%.2f d2d_gib=%.2f total_gib=%.2f sum_copy_ms=%.0f sum_compute_ms=%.0f sum_d2d_ms=%.0f med_compute_ms=%.2f" % (
                i, new, cached, r["wall_s"], r["h2d_gib"], r["d2d_gib"], r["h2d_gib"] + r["d2d_gib"],
                sum(x["copy_ms"] for x in L), sum(x["compute_ms"] for x in L), sum(x.get("d2d_ms", 0) for x in L),
                sorted(x["compute_ms"] for x in L)[len(L) // 2]))
EOF'
```

期望：

- 每个 `PROC` 行 `d0_records = prefill_lines − 1`，没有 `ALIGN-FAIL`。
- A、B、C 各有 2 行 `SEG … new=1 …`（规划阶段只读统计：每个 serve.log 有 2 行 `#new-token: 1,`；其中一行可能是最后一段而无 D0 记录，此时它不会被打印）。
