# R061 v4 OOM fault harness handoff

Formal entry: `development/r061_oom_owned_launch_v4.py`.
It is the only R061 v4 launch path: it verifies the candidate, native proof,
current full source closure, three frozen inputs, v4 FILEDRY receipt, sealed
approved PASS review, and sealed approved PASS pin before reservation.  The
child repeats that admission before validating its owned receipt and entering
the v3 physical protocol.

The v3 protocol is loaded once per body (`m.r060=lambda:rv`) and preserves the
same runtime module/port pair.  Its epoch observer writes an immutable index
to the raw PID directory; it never renames the worker directory or changes an
absolute `input_ids_path`.  Worker identities are selected from real
WorkerObserver PID receipts, excluding API-group helpers such as
`resource_tracker`.
