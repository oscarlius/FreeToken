- 当前 completion 接口拒绝 logprobs/echo，不能直接使用 CMMLU likelihood 命令。进一步核对实际部署版本 lm-eval 0.4.13：chat 生成适配器只返回正文，丢弃 finish_reason/reasoning_content/usage，task YAML 和 log_samples 无法补回。因此本次 lm-eval 仅用于独立文本基准，不接管 canonical quality60；quality60 采用 SDK 完整响应采集加既有离线判分器，全部逐题语义等价后才替换采集入口，不改变阈值，不推测缺失 finish_reason 为 stop。
- AIPerf 明确区分含 reasoning 的 TTFT 与首正文 TTFO。Locust/Toxiproxy 按后续具体缺口引入，本次先不增加依赖。
- 安装、CLI/import 自检、无 GPU 的协议 fixture 与真实目标模型验收分别记录。部署授权不等于批准待回复的 GPU 补跑，也不改变生产发布、release/e2、推送边界。
