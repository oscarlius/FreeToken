# Strata 可复用性评估（2026-10-05）

> 对象：`freetoken/_shared/Strata`（提交 `6f32ec0`，2026-10-04；`strata/Strata` 是 10-02 的旧克隆）。MIT 许可，与 FreeToken 的 Apache-2.0 兼容，移植时保留版权声明即可。
> 方法：阅读文档、源码抽查（`pool.cpp`、`expert_cache.cpp`、`prefill.cpp`、`peer_experts.cpp`、batching 与测试工具），并对照本项目计划卡的人日估计。**本文不含任何实测**。Strata 从未在本机测过（`_shared/framework-research-todo.md` 中只做了登记）。

## 0. 结论

1. **Strata 跑的是同一个模型（Qwen3.8-Flash-Next）**，路线是 CPU+GPU 混合：GPU 缓存热门专家，未命中的专家由 CPU 在主存原地计算，另有 MTP 投机解码。它是论文中**必须引用和对比的相关工作**，v4.0 漏掉了它，需要在 v4.1 补上。
2. 可复用的部分分为三类：
   - **近乎直接移植的代码**：CPU 线程池与亲和性模块。
   - **有实现可照着做的设计**：层切分多卡、批槽流水、自适应专家缓存、短块按需搬运、正确性测试方法。
   - **不可复用**：GGUF 格式的专用内核、sm_90+ 的 cluster 内核、HIP 后端。
3. **节省时间估计**（相对计划卡的人日）：
   - 不改路线：约 **6–14 人日**。
   - 多卡从 TP 改为层切分：再省约 **9–20 人日**。
   - 若重新纳入 MTP：再省约 **8–12 人日**。
   - 后两项都需要你决定。

## 2. 不需要开发、但建议立刻做的一件事：本机 Strata 基线（约 1 天）

- 在 4090 上用 IQ3_S（或 Q2_0）跑 Strata，按我们的套件测：冷 32K、64K、单路解码、两路并发、60 题（用规范判卷器）。
- 用途有三个：
  1. 论文对比基线：同一模型、同一硬件，但量化位数更低（2–3 bit 对 NVFP4 约 4.5 bit），对比时必须并列给出质量分数。
  2. 业务上的备选方案。
  3. 验证 Strata 的「CPU 原地计算」路线在本机**双路 DDR4、无 AMX** 条件下的实际速度。它的公开数据来自 DDR5 单路平台，不能外推到本机。
- 注意事项：
  - 实测前冻结自适应：`--adapt-every 100000 --prompt-cache 0 --adapt-swaps 0 --pcie-frac 0`。
  - 做 NUMA 对照。
  - 下载在工作时间限速 4.5 MB/s。
  - 代码放 `strata/` 目录，不放 `_shared/`（AGENTS.md 规定）。

## 3. 对论文的影响

- **相关工作**补入 Strata（同一模型的 CPU+GPU 混合系统，有论文 `docs/paper/Strata-Paper.pdf`）。差异写清四点：
  - 数值路径不同：NVFP4 对 2–3 bit GGUF。
  - 未命中处理不同：主要靠 PCIe 搬运，还是主要靠 CPU 原地计算。
  - 关注点不同：多会话 PCIe 预算，还是单会话体验。
  - 预填让出粒度不同：按层，还是按 token 块。
- 多卡部分把「层切分」列为与 TP 并列的候选配置，并引用其公开实测（命中率 99%+）。G0 的驻留率分析同样适用于层切分：每张卡只放自己那几层的专家。

## 4. 需要你决定的两件事

1. **多卡路线**：是否把「层切分（流水线并行）」作为 TP 之外的正式候选，甚至作为首选？它的工程量约为 TP 的三分之一，也不依赖 P2P；但单 token 延迟不会因为卡数增加而下降，收益主要来自专家常驻显存。方向稿曾写「真正的 TP」，所以需要你确认。
2. **MTP**：是否解冻？它是单会话解码最大的现成杠杆（宣称 1.6–1.8 倍），但会改变「冻结数值路径」的范围，并引入草稿验证的正确性门。
